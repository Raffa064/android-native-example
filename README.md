# Android Native Example
A cool native-only template for creating android apps in C/C++.

The project root directory contains a script `a.sh` (or `a.cmd` if you're on Windows) that simplifies building and running the native application.

## Fork Features
- ShellScript reimplementation for `a.cmd` (aka. the build script).
- Switched to aapt2.
- Added `res` directory
- Added comments for Makefiles
- Support for different naming convension for environment variables

## Project structure

All your source code must be done inside `jni` folder. Inside of it, there is two Makefiles, and your `main.c` which is the app's entry point.

Those Makefiles (Android.mk, and Application.mk) are used to configure the project compilation. Check them out for more infomration contained on their comments.

You can put *android resources* inside `./res` directory, and application assets inside `./assets` folder.

To configure app's permissions, name, package, icons, and whatever, use the `./AndroidManifest.xml`.

Any other file/directory on the root is probably autogenerated or related to git, so you can ignore them (Ex: obj/, bin/, lib/).

The initial main.c contains a OpenGL ES tringle rendering example, if you want a clean setartup file, replace it with `./jni/main.clean.c`. After replacing it, will propably want to delete the example shaders inside `assets` directory aswell.

## Original README
First either adjust `a.cmd` to have correct paths to Android SDK, Android NDK and Java SDK or set them in environment variables.
Then set `APK` varible to desired apk package name. Use Android SDK to install build-tools and platform SDK. 

Now you can use `a.cmd` to build, install and run the application:

    a [command]
    By default build, install and run .apk file.

    Optional [command] is:
      run       - only install and run .apk file
      build     - only build .apk file
      remove    - remove installed .apk
      install   - only install .apk file on connected device
      launch    - ony run already installed .apk file
      log       - show logcat
